# OZK StreamKit for OBS

**Твой OBS. Твои правила.** Бесплатные плагины для OBS Studio от [OTMOPOZOK](https://www.youtube.com/channel/UCTAKYR3T2Ud8zZgNShgQfyw/): чат Twitch, YouTube и Kick, уведомления о стриме, статистика трансляции и записи, мультистрим и тёмная тема.

Каждый плагин работает самостоятельно. Устанавливайте только то, что вам нужно. Оформление и панели выполнены в общей тёмной палитре.

| Компонент | Что делает |
| --- | --- |
| [OZK Chat](https://github.com/DIMI0007/ozk-chat) | Собирает чаты Twitch, YouTube и Kick в OBS; позволяет отвечать в выбранные чаты. |
| [OZK Notify](https://github.com/DIMI0007/ozk-notify) | Отправляет анонсы эфира в Telegram и Discord, показывает состояние трансляций и донатов. |
| [OZK Stats](https://github.com/DIMI0007/ozk-stats) | Показывает нагрузку, запись и каждый поток с его битрейтом. |
| [OZK Multi](https://github.com/DIMI0007/ozk-multi) | Запускает несколько горизонтальных выходов из одной OBS. Основан на Aitum Multistream; авторство и лицензия оригинала сохранены. |
| [OZK Dark](https://github.com/DIMI0007/ozk-dark) | Меняет цвета стандартных панелей и верхней части OBS. |

## Как установить

1. Выберите нужный компонент в таблице и откройте его страницу.
2. Прочитайте раздел **«Как установить»** на этой странице и скачайте подходящий архив.
3. Закройте OBS перед заменой файлов. После установки запустите OBS и откройте нужную панель в меню **«Док-панели»**.

Сейчас сборки предназначены для **OBS Studio 33 на Windows x64**. Инструкции по созданию личных приложений Twitch, YouTube и Kick находятся в [руководстве OZK Chat](https://github.com/DIMI0007/ozk-chat/blob/main/docs/REGISTER_APPS_RU.md). У каждого компонента есть своя инструкция и страница загрузки.

## Как компоненты работают вместе

OZK Stats может показывать нагрузку и сетевой трафик OZK Chat и OZK Notify. OZK Notify может использовать входы Chat для проверки эфира, если оба плагина установлены. OZK Multi создаёт дополнительные выходы OBS, которые Stats учитывает в общей статистике. Без остальных компонентов каждый плагин сохраняет свои основные функции.
