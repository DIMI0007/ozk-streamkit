# Обновление отзывчивости OZK — 3 ноября 2026

Установлены OZK Chat 0.4.6, Notify 1.0.18, Stats 1.1.7, Donations 0.5.4, Multi 0.1.7.

- Chat: картинки обновляют ресурсы документа и отдельные смайлы без пересоздания всей истории; размеры смайлов проверяются до распаковки; обработка входящих сообщений ограничена бюджетом времени.
- Notify: обычное автосохранение выполняется в последовательной фоновой очереди; шифрование неизменившихся секретов переиспользуется; повторная загрузка неизменившихся файлов входа использует расшифрованные данные в памяти. Запись журнала перед отправкой анонса остаётся подтверждаемой синхронной операцией для защиты от дублей. На медленном диске этот критический путь ещё может задержать интерфейс: для него потребуется отдельная схема асинхронного подтверждения перед отправкой, если замеры покажут задержки.
- Stats: проверка файла записи и свободного места выполняется отдельно от GUI, впервые при начале записи, затем раз в минуту. При смене пути запрашивается новое измерение. Битрейт, время и скорость продолжают обновляться раз в секунду по счётчикам OBS.
- Donations: кеш читается и записывается в фоне; первые запросы сервисов разнесены; карточки истории создаются порциями до 8 за проход с бюджетом времени; готовые карточки сохраняются при повторных обновлениях.
- Multi: периодический опрос реже в простое и при скрытой панели; запуск кодировщиков не перенесён в произвольные потоки, поскольку для OBS API нужно соблюдать требования потоков.
- Добавлена редкая диагностика: операции дольше 100 мс и интервалы GUI больше секунды попадают в журнал OBS без ключей и содержимого сообщений. Сам факт задержки GUI не устанавливает виновный модуль.

## Проверки

Все пять Windows-сборок прошли CI. Существующие тесты и проверки интерфейсов прошли; Notify дополнительно проверен на сохранение фонового снимка настроек. Donations проверяет сохранение карточки после 100 уведомлений об обновлении. Скачанные архивы сверены с SHA-256 артефактов GitHub; установленные DLL сверены с пакетами. OBS запущен, загрузка пяти версий подтверждена журналом. Перед заменой созданы резервные копии файлов плагинов.

Это не длительный нагрузочный тест. Одновременный эфир на несколько площадок, запись на медленный диск, массовый чат и все варианты сетевых обрывов в этой проверке не запускались. В момент старта OBS зафиксирована задержка GUI 1455 мс; причинная связь с конкретным плагином не установлена. Прежние паузы 2–5 секунд необходимо проверить при обычной работе пользователя.
